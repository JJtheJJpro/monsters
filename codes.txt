Always 1 byte.

- If bit 7 is clear, follow Monster Code.
- If bit 7 is set, follow Special Code.



Monster Code:

Bit 6
- 0 (Off)
- 1 (On)

The rest of the bits are the monster number (starting at 1, not 0.  0b01000000 is not a valid monster command).



Special Code:

- 0000000 : USB Takeover
- 0000001 : Net Takeover
- 0000010 : Send Data (Off)
- 0000011 : Send Data (On)
- 0000100 : Testing End
- 0000101 : Testing Begin
- 1111111 : Reset

The rest of the codes are reserved.
